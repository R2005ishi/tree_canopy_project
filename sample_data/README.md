# Sample data

No imagery is bundled here — real forest aerial/satellite imagery is either
copyrighted or too large to ship in a repo, and this tool refuses to fake data.

To test locally, use your own drone/aerial photo (PNG/JPG) or GeoTIFF orthomosaic, or grab a free
NEON tile (the biome DeepForest was trained on) from the NEON Data Portal:
https://data.neonscience.org/data-products/DP3.30010.001 (RGB camera orthomosaics).
